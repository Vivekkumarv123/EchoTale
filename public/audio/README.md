# EchoTale Ambient Audio Directory

Place your CC0 or royalty-free ambient audio file here:
- Recommended filename: `ambient-pad.mp3`
- Recommended audio type: Soft rain, gentle ambient drone, or quiet parchment sound loop.
- License requirement: Freesound CC0, Pixabay Audio, or public domain.

Note: EchoTale includes a Web Audio procedural synthesizer fallback if this MP3 file is not present.
